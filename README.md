# .github

The Coke &amp; Code Dev organisation profile.

- `profile/README.md` is the page shown on [github.com/Coke-and-Code-Dev](https://github.com/Coke-and-Code-Dev).
- `profile/assets/` holds the banner, logo, member cards and buttons it uses.
- The "Tools we reach for" icons are refreshed daily by `.github/workflows/update-tools.yml`, which scans the organisation's public repos.
